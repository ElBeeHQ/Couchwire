# Couchwire 0.2.3: A fix for a black screen

*23 November 2026*

Fixes a black screen when the PS5 turns down the first request to start a stream.

### Fixed

- The stream no longer stays black when the PS5 turns down the first request and Couchwire quietly tries again. The picture was arriving, but the window kept showing the first try's empty video.

**Update:** Couchwire 0.1.0 and later offer this update by themselves; or choose **Couchwire › Check for Updates…**. New here? Download `Couchwire-0.2.3.dmg`, open it, and drag Couchwire onto Applications. Needs macOS 14 or later on Apple silicon. The app is not notarised, so the first time macOS may say it cannot verify it: open System Settings > Privacy & Security, scroll to the message about Couchwire and click **Open Anyway**.

**Source:** Couchwire is free software under the GNU AGPL v3. `Couchwire-0.2.3-source.tar.gz` is the source of this release, including chiaki-ng, and `Couchwire-0.2.3-dependencies-source.tar` holds the exact sources of the libraries it's built with.
